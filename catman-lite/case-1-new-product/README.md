# Case 1 — новинка конкурента → решение Catman

Цель Lite: за короткую демонстрацию показать, как AI-агент превращает найденный во внешнем ассортименте товар в проверяемое решение категорийного менеджера: не менять матрицу, запросить данные либо провести ограниченный тест. Исследование реальных карточек сочетается с явно синтетическими внутренними данными условной сети; чужие продажи, наша прибыль и эффект пилота не выдумываются.

Сначала агент выбирает одну несложную non-food категорию и один публично доступный каталог сети как **референс для демо-матрицы**; фиксирует категорию, регион/магазин, дату среза и ограничения источника. Это НЕ утверждение, что у нас есть внутренние данные выбранной реальной сети. Затем исследует другие открытые витрины и отбирает одного кандидата с доказательствами и альтернативами. Выбор конкретного ритейлера, категории и прав использования публичного каталога остаётся задачей discovery; никаких источников заранее не объявлять проверенными.
