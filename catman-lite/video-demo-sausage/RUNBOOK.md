# Воспроизведение данных v1

Выполнить из папки пакета: `python generate_demo.py data` и затем `python validate_demo.py data`. Нужен только Python 3 (стандартная библиотека). Генератор с фиксированным seed=42026 создаёт шесть CSV и файлы `manifest.json`, `case_evidence.json`. Срез: 2026-09-27; 7 вымышленных SKU, 6 вымышленных магазинов, 28 дней, 840 строк продаж и 120 партий. Данные синтетические, реальных чеков X5 или реальных карточек OFF в них нет.

Case 1: `K07` — кандидат, которого ещё нет в продажах; `K02` — товар для сравнения; `M01/M02` — пилот. За последние 7 дней в синтетической истории K02 продан 41 раз в этих двух магазинах. Для K07 не заявлять наблюдаемые продажи или измеренный uplift.

Case 2: `M01–M03` и `M04–M06` — предзаданные группы вымышленной сети. Сравнивать общие SKU K01/K02/K03 только по дням без OOS; не называть метки кластеров результатом обученной модели без отдельного расчёта.

Case 3: партия `M01-K03-21` на срезе 2026-09-27 содержит 46 шт. и истекает 2026-10-01. Средний темп продажи K03 за 7 дней: 10/7 шт. в сутки; модельный остаток к сроку: 40,3 шт. Это детерминированная оценка, не вероятность. Для экономического решения дополнительно рассчитать и явно пометить допущения об уценке/перемещении.

Тесты сверяют ключи, баланс партии на каждый день, свод продаж, OOS и происхождение SKU кандидата. Этот пакет ещё не содержит финального видеосценария и сравнения альтернативных P&L-сценариев. После расчёта их следует добавить до съёмки.
