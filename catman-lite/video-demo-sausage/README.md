# Catman Lite — видео-демо по колбасным изделиям

Статус: стартовый контракт, НЕ готовый датасет и НЕ готовый ролик. Дата среза: 2026-09-28. Валюта: RUB.

Цель: дать следующему AI-агенту единый проверяемый пакет для видео о трёх решениях категорийного менеджера: новинка/замена SKU, кластерная локальная матрица, риск списания партии. Все три сцены должны работать в одном демо-мире на общих ID товаров и магазинов.

Сначала читать DATA_CONTRACT.md, затем CASE_MAP.md и VIDEO_AGENT_BRIEF.md. Следующие артефакты, которые пока НЕ созданы: генератор данных, CSV/Parquet, тесты инвариантов, расчётные доказательства, финальный сценарий и шот-лист. Не начинайте финальную съёмку до появления этих артефактов и прохождения тестов.

Старые материалы в catman-lite/case-1-new-product/, catman-lite/case-2-dairy-clustering/ и catman-lite/case-3-expiry-risk/ — исторические черновики; молочную категорию не переносить. Эта папка станет единым видео-пакетом, оригиналы не редактируем.

Происхождение: продажи, магазины, цены, остатки и партии в первой версии будут явно синтетическими. Реальные карточки колбасных товаров можно добавить позже только с атрибуцией источника, проверенными идентификаторами и условиями использования. Запрещено выдавать анонимные продажи X5 RetailHero за продажи именованных колбасных SKU.
