# Roadmap

## Phase 0 — Contract spike

- Event envelope schema.
- Artifact envelope schema.
- TypeScript protocol types.
- Mock adapter and mock store.
- Basic fixtures and validation.

## Phase 1 — Reference UI

- Rooms sidebar.
- Chat timeline.
- Progress trace.
- Artifact Canvas.
- Component registry.
- Provenance drawer.
- Save, version and export.

## Phase 2 — Runtime adapters

Integrate two different runtimes using the same protocol and renderer.

## Phase 3 — Catman domain package

Deliver Promo and Assortment rooms, `promo-analysis`, `assortment-review`, `cdt-builder` and scenario comparison.

## Phase 4 — Proactive workflows

Watchlists, alerts, scheduled runs and approval/undo controls.

## Success metrics

- Time from request to usable artifact.
- Reproducibility and provenance coverage.
- Reuse of saved artifacts.
- Time to decision.
- Runtime portability.
- Cost per completed workflow.
